# Architecture Profile Contracts

This bundle defines the sole deployable thesis profile:
`six-layer-eventing@1`.

The profile is closed-world and self-contained. It owns all L1-L6 logical
components, provider implementations, component catalog entries, workload
compatibility, and resolved-architecture evidence. It does not inherit another
runtime profile.

Contract schemas remain at v2 because that is the schema generation, not an
architecture-profile version. Canonical definitions live under
`definitions/`; synchronized service copies are generated by
`scripts/sync_six_layer_contracts.py`.

The original Five-layer calculation remains an Optimizer-only historical
baseline and is deliberately absent from this shared runtime contract.
