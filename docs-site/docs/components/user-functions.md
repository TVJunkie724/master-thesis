# User-function components

Twin2MultiCloud supports a closed set of user-function roles needed by the
university scenario. Typed Twin configuration stores the current draft source
and metadata; deterministic validation and provider wrappers turn it into a
graph-selected runtime package.

The component boundary deliberately excludes an artifact marketplace,
arbitrary provider packages, dependency discovery and long-lived version or
ownership administration. See the user guide and developer guide for the
supported input and validation rules.
